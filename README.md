# 🤖 Juegos Bonaerenses de Robótica

Proyecto web simple en HTML sobre los **Juegos Bonaerenses de Robótica**, pensado para compartir información básica sobre esta competencia educativa y tecnológica.

---

## 📌 Descripción

Este proyecto contiene una página web sencilla desarrollada en **HTML y CSS**, diseñada para presentar:

- Qué son los Juegos Bonaerenses de Robótica.
- Sus objetivos educativos.
- La importancia de la tecnología y la innovación.
- Información básica para estudiantes y escuelas.

---

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
